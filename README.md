# BW_Databricks_Pipeline_Project
Dynamic Sales Reporting Pipeline (Databricks, Spark SQL, Delta Lake, Python)

Designed and built a parameterized data pipeline in Databricks to simulate client-facing reporting workflows across daily, weekly, and monthly time horizons

Implemented dynamic date controls using Databricks widgets and Python, enabling flexible, user-driven analysis without modifying code

Developed aggregation workflows in Spark SQL to generate location-level performance metrics from structured datasets

Persisted outputs to Delta Lake tables, supporting scalable storage and downstream analytics use cases

Structured solution as a reusable analytics prototype, demonstrating how business users can interact with data through parameterized inputs

Automated time-based reporting workflows, reducing manual analysis effort and improving repeatability
